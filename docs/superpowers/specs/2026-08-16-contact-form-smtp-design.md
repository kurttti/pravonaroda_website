# Отправка заявок на support@pravonaroda.ru

## Цель

Включить существующую форму на главной странице и доставлять заявки клиентов на `support@pravonaroda.ru` через SMTP SpaceWeb. Пароль почтового ящика не должен попадать в Git, публичную папку сайта, клиентский JavaScript или журналы сборки.

## Выбранный подход

Основной сайт на `pravonaroda.ru` остаётся статическим, а отправку выполняет небольшой PHP-обработчик на SpaceWeb. Для SMTP используется PHPMailer и официальные параметры SpaceWeb:

- сервер `smtp.spaceweb.ru`;
- порт `465`;
- шифрование SSL;
- логин и адрес отправителя `support@pravonaroda.ru`;
- адрес получателя `support@pravonaroda.ru`.

Этот вариант выбран вместо PHP `mail()`, потому что SpaceWeb предупреждает: сообщения от технического адреса сервера могут отклоняться или попадать в спам. Внешний сервис форм не используется, чтобы не передавать заявки третьей стороне.

## Компоненты

### Форма

Форма сохраняет три основных поля:

1. имя;
2. номер телефона;
3. описание ситуации.

Дополнительно появятся:

- обязательный флажок согласия на обработку персональных данных со ссылкой на политику конфиденциальности;
- скрытое поле-ловушка для ботов;
- область со статусом отправки, доступная экранным дикторам.

Кнопка «Отправить заявку» будет включена. Во время отправки она временно блокируется и показывает состояние «Отправляем…».

### Клиентская отправка

Форма отправляет данные методом `POST` на `/api/send-request.php` без перезагрузки страницы.

- При успехе поля очищаются и появляется сообщение: «Заявка отправлена. Мы свяжемся с вами по указанному номеру».
- При ошибке введённые данные сохраняются, показывается понятное сообщение и ссылка для звонка.
- Повторное нажатие во время отправки не создаёт вторую заявку.

### Серверный обработчик

PHP-обработчик принимает только `POST` и возвращает JSON. Он:

- проверяет, что запрос пришёл с сайта `pravonaroda.ru`, когда браузер передал `Origin` или `Referer`;
- отклоняет заполненное поле-ловушку;
- проверяет имя, телефон, описание и согласие;
- принимает имя длиной 2–80 символов, телефон с 7–20 цифрами и описание длиной 10–4000 символов;
- допускает не более пяти попыток за 15 минут с одного IP;
- не помещает пользовательские значения в SMTP-заголовки без обработки;
- отправляет текстовое UTF-8 письмо через PHPMailer;
- не раскрывает пользователю технические ошибки SMTP.

Письмо содержит дату и время по Москве, имя, телефон и описание ситуации. Тема: «Новая заявка с pravonaroda.ru».

## Защита данных и секрета

Пароль берётся из локального файла `.openai/креды sweb.ru`, который уже исключён из Git. На хостинге он сохраняется в `/pravonaroda_ru/private/mail-config.php`, то есть выше `public_html`; PHP-обработчик читает его на сервере. Публичная сборка и репозиторий содержат только пример структуры конфигурации без пароля.

Ограничитель частоты хранит только односторонний хеш IP и время попыток в закрытой серверной папке. Текст заявок не записывается в файлы и остаётся только в почтовом ящике.

## Политика конфиденциальности

На сайте появится отдельная статическая страница `/politika-konfidencialnosti/`. В ней указываются действующий оператор сайта, состав собираемых данных, цель обработки — ответ на обращение, способ передачи формы и порядок отзыва согласия через `support@pravonaroda.ru`. Данные хранятся до достижения цели обработки или отзыва согласия, если иной срок не требуется законом.

## Развёртывание

- Клиентская часть и PHP-обработчик собираются в `spaceweb-dist` и публикуются текущим GitHub Actions-процессом в `public_html`.
- SMTP-конфигурация с паролем загружается отдельно в закрытую папку и не удаляется при следующих публикациях сайта.
- PHPMailer фиксируется на версии `6.12.0`, совместимой с используемой на хостинге веткой PHP 7, чтобы сборка была воспроизводимой.
- Версия Sites также публикуется для сохранения текущего процесса проекта, но рабочая SMTP-отправка относится к основному домену на SpaceWeb.

## Проверка и критерии готовности

До публикации:

- тест разметки подтверждает наличие рабочего действия формы, согласия и страницы политики;
- тесты PHP подтверждают отклонение пустых, слишком длинных и подозрительных запросов;
- сборки Sites и SpaceWeb проходят без ошибок;
- секрет отсутствует в Git и готовых публичных файлах.

После публикации:

- выполняется одна тестовая заявка с заведомо тестовыми данными;
- сервер возвращает успешный ответ;
- тестовое письмо появляется в `support@pravonaroda.ru`;
- неверный запрос получает понятную ошибку и не отправляет письмо.

## Не входит в эту задачу

- личный кабинет и база заявок;
- вложения к форме;
- автоматические ответы клиенту, поскольку в форме нет поля электронной почты;
- рассылки и рекламные сообщения.
