# Интеграция формы сайта с Bitrix24 CRM

Заявка отправляется из серверного PHP-обработчика одновременно в два канала:

- в Bitrix24 как лид через `crm.item.add`;
- на `support@pravonaroda.ru` через существующий SMTP.

В карточку лида попадают имя, телефон, описание ситуации и пометка источника `Форма на сайте pravonaroda.ru`. URL входящего вебхука является секретом и не попадает в Git, клиентский JavaScript или публичную папку сайта.

## 1. Проверить режим CRM

Интеграция рассчитана на классический режим CRM с лидами. В простом режиме Bitrix24 автоматически конвертирует новый лид в сделку. Режим можно проверить в настройках CRM или REST-методом `crm.settings.mode.get`.

## 2. Создать входящий вебхук

В Bitrix24 откройте **Приложения → Разработчикам → Готовые сценарии → Другое → Входящий вебхук**.

1. Назовите вебхук `Заявки с pravonaroda.ru`.
2. Выберите право доступа **CRM (crm)**.
3. Создавайте вебхук от имени сотрудника, у которого есть права добавлять и читать лиды.
4. Скопируйте только базовый URL вида `https://portal.bitrix24.ru/rest/1/секретный-код/`.

Не добавляйте к URL имя метода и не отправляйте URL в переписку.

## 3. Сохранить секрет на SpaceWeb

Через файловый менеджер панели SpaceWeb или SFTP создайте файл `/pravonaroda_ru/private/bitrix24-config.php` по образцу `spaceweb/config/bitrix24-config.example.php`. Замените только значение `webhook_url` на URL из шага 2 и установите права файла `600`.

Не загружайте этот файл через текущий GitHub Actions workflow: он использует обычный FTP без шифрования. Файл находится вне `public_html`, не включается в сборку и не удаляется при последующих деплоях.

Если закрытого файла нет, сайт продолжит отправлять письма, но CRM-канал останется отключён.

## 4. Проверить обязательные поля и тестовую заявку

Если в лидах настроены пользовательские обязательные поля, Bitrix24 отклонит заявку, пока они не будут добавлены в `build_bitrix24_lead_payload()`. Список можно получить методом `crm.item.fields` с `entityTypeId: 1`.

После деплоя отправьте одну тестовую заявку с сайта. В CRM должен появиться лид `Заявка с pravonaroda.ru — Тест`, а на почту — обычное письмо. Проверьте имя, телефон и комментарий в карточке, после чего удалите тестовый лид.

Если один канал временно недоступен, второй всё равно сохраняет заявку. Техническая ошибка записывается в закрытый журнал инцидентов на сервере, а URL вебхука в сообщение не включается.
